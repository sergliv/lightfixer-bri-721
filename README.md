# LightFixer BRI-721  —  версия 1.0

Фиксер подсветки клавиатуры ноутбука **HONOR X16 Plus BRI-721** под Windows 11.

Английская версия: [README.en.md](README.en.md)

Программа включает подсветку клавиш при работе за ноутбуком (по клавиатуре и по
мыши) и выключает её после заданного простоя — чтобы не светить впустую и не жечь
батарею. Дополнительно умеет выставлять яркость сразу после включения ноутбука.

## Возможности

- Подсветка включается при нажатии клавиш и (по желанию) при движении мыши.
  В штатных настройках HONOR включения от мыши нет — подсветка поднимается только
  от нажатия клавиш; этот вариант добавляет программа.
- Выключается после простоя: готовые значения от 1 секунды до 2 часов, либо своё
  время в часах, минутах и секундах; либо не выключается вовсе.
- Подсветка при включении ноутбука: выключена / низкая / высокая / не менять
  (как было). В штатных настройках HONOR яркость после запуска задать нельзя —
  подсветка включается сама только через эту программу.
- Переключатель на штатное управление HONOR — программа ничего не трогает,
  подсветкой распоряжаются настройки ноутбука.
- Клавиши **Fn+Пробел** работают всегда, как и без программы: ими можно в любой
  момент включить, выключить или сменить яркость подсветки — точно так же, как
  в штатном режиме ноутбука.
- Работает в трее, автозапуск при входе в Windows, настройки сохраняются.

## Как запустить

1. Положить `LightFixer-BRI-721.exe` в любую постоянную папку (например,
   `C:\LightFixer`). Рядом программа хранит `settings.json`,
   поэтому папка должна быть постоянной и доступной для записи.
2. Запустить от имени администратора (программа сама попросит).
3. Настроить и нажать «Сохранить».

При первом запуске программа сама создаёт задачу в Планировщике заданий
(запуск через 15 секунд после входа в Windows) и дальше стартует молча, в трее.
Больше подтверждений не будет. В меню значка в трее есть пункт «О программе».

Автозапуск управляется галочкой «Запускать программу вместе с Windows» в блоке
«Подсветка клавиатуры при включении ноутбука»: сняли галочку и нажали
«Сохранить» — задача в Планировщике отключается, вернули — включается.
Вторая галочка, «Включать подсветку до входа в Windows», управляет отдельной
задачей: снятая, она удаляется из Планировщика.

Задачи называются **LightFixer BRI-721** и **LightFixer BRI-721 (загрузка)**.
Их видно в Планировщике заданий (Win+R → `taskschd.msc`), но трогать их там
не нужно: программа сама приводит их в соответствие с галочками.

Настройки хранятся в файле `settings.json` рядом с программой — папка должна быть
доступна для записи. Журнал работы (для диагностики) —
`%LOCALAPPDATA%\LightFixer\lightfixer.log`, открывается из меню значка в трее.
Если перенести `.exe` в другую папку, задача автозапуска обновится сама при
следующем запуске программы.

В режиме «Штатные настройки HONOR» программа не подаёт никаких команд подсветке:
не задаёт яркость, не меняет таймаут BIOS. Она только следит за состоянием и
показывает его в окне.

Требуется .NET Framework 4.x (в Windows 11 входит в состав системы).
ОС: Windows 10 / 11, ноутбук HONOR X16 Plus BRI-721. На других моделях работа
не гарантируется.

## Сборка из исходников

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -nologo -target:winexe ^
  -win32manifest:app.manifest ^
  -r:System.Management.dll -r:System.Windows.Forms.dll -r:System.Drawing.dll ^
  -out:LightFixer-BRI-721.exe LightFixer.cs
```

Либо `powershell -ExecutionPolicy Bypass -File build.ps1`.

Для сборки рядом должны лежать `app.manifest` и два файла иконок: `app.ico`
(полный набор 16–256 для самого файла программы) и `app-small.ico` (16–64,
встраивается внутрь для значка в трее и заголовке окна). Оба набора рисуются
скриптом `_icon.ps1` — он создаёт их заново с нуля, без внешних файлов.

## Как это работает

Утилита обращается к штатному интерфейсу, который Windows сама предоставляет для
этого устройства: WMI-пространство `root\wmi`, класс `OemWMIMethod`, метод
`OemWMIfun`, объект `ACPI\PNP0C14\HWMI_0`. Это документированный механизм
ACPI-WMI mapping, он виден любому процессу с правами администратора и не требует
ни драйверов, ни чужого программного обеспечения.

Значения параметров (номера команд: режим подсветки и таймаут) определены
по данным самого устройства — анализ таблиц ACPI и перебор методов WMI-объекта
на ноутбуке этой модели, а также по ранее опубликованным открытым сведениям.

Исходный код утилиты оригинален, написан с нуля. В поставке нет ни одного файла
HONOR: ни исполняемых, ни изображений, ни текстов. Номера команд WMI определены
по таблицам ACPI самого ноутбука и по открытым публикациям, а не декомпиляцией
чужого программного обеспечения.

## Безопасность и расход батареи

**Сети в программе нет.** В исполняемом файле отсутствуют сетевые компоненты
(`System.Net`, `Socket`, `TcpClient`, `HttpWebRequest`, `WebClient`), во время
работы программа не держит ни одного сетевого соединения. Единственные адреса
в файле — служебные схемы Microsoft из манифеста.

**Реестр и другие процессы.** Программа не обращается к реестру, не загружает
сторонние библиотеки, не внедряется в другие процессы. Из системных библиотек
используются только `user32.dll` (стандартная библиотека Windows) и один
WMI-метод прошивки.

**Клавиатура.** Чтобы подсветка возвращалась после простоя, программа ставит
системный хук клавиатуры (`SetWindowsHookEx`). В обработчике сохраняется
**только время** последнего нажатия: ни код клавиши, ни набранный текст
не читаются и нигде не записываются.

**Права.** Программа работает с правами администратора — иначе ACPI-метод
прошивки недоступен. Загрузочная задача выполняется от имени SYSTEM, чтобы
подсветка горела уже при вводе пароля Windows.

**Важно при установке.** Ставьте программу в папку, куда может писать только
администратор, например `C:\Program Files\LightFixer\`. Если положить её
в папку с общим доступом на запись, подмена исполняемого файла даст выполнение
чужого кода с правами администратора, а при загрузке — с правами SYSTEM.

**Расход заряда.** Пока вы работаете, программа спрашивает у прошивки текущий
режим 10 раз в секунду: иначе не поймать нажатие Fn+Пробел (прошивка держит шаг
«авто» около 50 мс). Замер на этой модели — **около 0,7 % одного ядра**, то есть
примерно 1–2 % времени автономной работы. Когда клавиатура и мышь не трогаются
дольше 30 секунд, опрос прекращается и расход падает почти до нуля.

**Сон ноутбука.** Программа не запрещает переход в сон (не вызывает
`SetThreadExecutionState`), не создаёт таймеров пробуждения, задача Планировщика
не будит ноутбук. После выхода из сна подсветка 20 секунд не трогается, чтобы
не мешать прошивке восстановиться.

## Подсказка на экране (HONOR)

При переключении Fn+Пробел ноутбук показывает свою подсказку. Её рисует программа
HONOR `OSD_Daemon.exe` из папки `C:\Program Files\HONOR\OSD`; эти файлы ставит
HONOR PC Manager 18.0.0.81 (C001HONOR). **LightFixer эти файлы не читает и не
изменяет** — подсказка на экране всегда заводская.

Из-за этого возможна одна нестыковка. На шаге «авто» подсветка фактически горит
на низкой яркости (программа сразу переводит этот шаг в «низкую»), а подсказка
показывает слово «Авто». Так задумано производителем, и LightFixer это слово не
правит: файлы производителя остаются нетронутыми.

Когда яркость меняется из окна программы (кнопка «Сохранить»), HONOR свою
подсказку не показывает — изменение яркости видно по самой клавиатуре.
